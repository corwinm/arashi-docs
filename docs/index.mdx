<p class="home-mantra"><strong>嵐 (Arashi) - The eye of the storm for your development workflow</strong></p>

Arashi manages aligned worktrees across multiple repositories within a shared meta-repository. It streamlines creating, switching, and managing changes across your whole stack.

Arashi makes a polyrepo work like a monorepo during development, while every repository keeps its own history, CI, and pull requests.

<script is:inline>{`
  (() => {
    const typingCadence = 24;
    const completionHold = 0.18;
    const treeReplayAnimations = new Set(["tree-root-window", "tree-root-window-safari"]);

    const initializeHomepageTyping = () => {
      for (const demo of document.querySelectorAll(".demo-sequence")) {
        if (demo.dataset.typingInitialized === "true") continue;

        const demoCycle = Number.parseFloat(getComputedStyle(demo).getPropertyValue("--demo-cycle"));
        const typingElements = [...demo.querySelectorAll(".terminal-line .typing")];
        for (const typing of typingElements) {
          const typed = typing.querySelector(".typed");
          if (!typed) continue;

          const characterCount = Array.from(typed.textContent ?? "").length;
          const typingDuration = characterCount / typingCadence;
          const outputStart = Number.parseFloat(getComputedStyle(typing).getPropertyValue("--output-start"));
          typing.style.setProperty("--steps", String(characterCount));
          typing.style.setProperty("--typing-duration", String(typingDuration) + "s");
          typing.style.setProperty(
            "--typing-delay",
            String(outputStart * demoCycle - typingDuration - completionHold) + "s"
          );
        }

        demo.dataset.typingInitialized = "true";
        demo.classList.add("typing-ready");

        demo.querySelector(".tree-canvas")?.addEventListener("animationiteration", (event) => {
          if (!treeReplayAnimations.has(event.animationName)) return;

          for (const typing of typingElements) typing.style.animationName = "none";
          void demo.offsetWidth;
          for (const typing of typingElements) typing.style.removeProperty("animation-name");
        });
      }
    };

    initializeHomepageTyping();
    document.addEventListener("astro:page-load", initializeHomepageTyping);

    const syncKey = "starlight-synced-tabs__install-method";
    const platform = navigator.userAgentData?.platform ?? navigator.platform ?? "";

    if (!localStorage.getItem(syncKey) && /win/i.test(platform)) {
      localStorage.setItem(syncKey, "Windows");
    }
  })();
`}</script>

## Choose Your Path

- New to Arashi? Follow the [Quickstart](/getting-started/).
- Starting or returning to a change? Use [Work on a Change](/workflows/change-lifecycle/).
- Coordinating several repositories? Use [Coordinate Repositories](/workflows/coordinate-repositories/).
- Want every new worktree prepared automatically? Use [Setup and Cleanup](/workflows/setup-and-cleanup/).
- Connecting Arashi to an editor, terminal, or workspace manager? Open [Integrations](/workflows/environment-integrations/).
- Working with coding agents or automation? Open [Coding Agents](/workflows/agents-and-specs/) or [Scripts and CI](/workflows/automation/).
- Looking for exact behavior? Open [Reference](/reference/) or [Commands](/commands/).
- Contributing to Arashi? Open [Contributing](/contributing/).
- Need Arashi in a project that has not adopted workspace configuration? Use [Arashi in One Repository](/getting-started/standalone/).

Configured mode is preferred whenever it is available—even for one repository—because it supports hooks, defaults, custom paths, and coordination. Standalone mode provides an ad hoc `.worktrees/<branch>` convention for an otherwise-unconfigured project.
