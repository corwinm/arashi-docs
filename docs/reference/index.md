Use this section when you need exact supported behavior rather than a task-oriented guide.

- [Configuration](/reference/configuration/) describes workspace layout, repositories, groups, base branches, worktree paths, copied files, symlinks, and command defaults.
- [Lifecycle Hooks](/reference/hooks/) defines lifecycle order, discovery, input, environment variables, platform behavior, timeouts, outcomes, and failures.
- [Launching, Tabs, and Precedence](/reference/launching/) defines default launch disposition, one-invocation tab requests, managed-context precedence, and launcher support.

For command-line options and command-specific output, continue to [Commands](/commands/). For guided use, return to [Workflows](/workflows/).
